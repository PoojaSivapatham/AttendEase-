AttendEase – Employee Attendance Management System

AttendEase is a web-based employee attendance management application designed to simplify employee management, daily attendance tracking, and attendance history.

Features

- Add and manage employee records
- Mark daily attendance
- Track Present, Absent, and Leave statuses
- View attendance history
- View attendance summaries on the dashboard
- Export attendance records as a CSV file
- Store data locally in the browser using localStorage

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages for hosting


  How to Run

1. Open the project repository on GitHub.
2. Download or clone the repository.
3. Open "index.html" in a web browser.

No additional software installation is required to run the basic frontend application.

Data Storage

AttendEase uses browser localStorage to store employee and attendance information. The data is stored locally in the browser and is not synchronized across different users or devices.

Current Limitations

- Data is stored locally in the browser.
- There is no shared backend database or user authentication.
- Data may be lost if the browser's site data is cleared.

Future Improvements

- Add a backend database for centralized data storage.
- Implement secure user authentication and access control.
- Add more detailed attendance reports and filters.
